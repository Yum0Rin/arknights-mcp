# 工作流：游戏内仓库取数（OCR 读库存）

> 为什么需要：MAA 的 `ark_depot`（Depot 任务）只识别「基础物品」那批模板，
> **拿不到 `ap_supply_lt_*`（理智药）等消耗品**；森空岛接口**没有仓库**。
> 所以「理智药存量 / 消耗品」只能**进游戏仓库页用 OCR 读**。
> 本流程一次探索、以后复用：只要再进仓库页，截图 + 局部 OCR 即可出库存。

## 1. 进仓库

- **路线 A（推荐，稳）**：直接跑 MAA 的 Depot 任务 → MAA 会自己从主界面导航到仓库并识别：
  ```
  ark_depot(timeout_s=240)     # 或 ark_run_task("Depot")
  ```
  跑完游戏就停在「仓库」页；再截图处理。注意它会跑识别（~50s），且需 MAA 空闲 + 游戏在主界面。
- **路线 B（手点）**：主界面 → 仓库入口。主界面底部/侧边有「仓库」按钮（图标随主题变化，
  MAA 模板 `resource\template\UiTheme\<主题>\DepotEnter.png` 可定位；默认主题在 `UiTheme\Default\DepotEnter.png`）。
  本机当前用的是活动主题，`UiTheme\Default\DepotEnter.png` **匹配不到**，故走路线 A 更省事。

## 2. 仓库页结构（1920×1080）

顶部**分类 tab**（从左到右）：

| tab | 坐标(点) |
|---|---|
| 全部 | ≈ (755, 57) |
| 消耗物品 | ≈ (978, 57) |
| 基础物品 | ≈ (1190, 57) |
| 养成材料 | ≈ (1440, 57) |
| 特别纪念 | ≈ (1680, 57) |

- 网格：每行 8 个（1920 下首三行 y ≈ 300 / 555 / 800，x 起点 ≈ 185，列距 ≈ 238）。
- 道具角标即为数量；带圆钟角标的是**限时**道具（如 `8天`/`1天`）——理智药常有限时批次。

## 3. 读某道具的「名称 + 到期 + 库存」

1. 点网格里的道具 → 弹出详情面板（左侧大图，右侧「库存 N」，标题栏「名称 + 到期时间」）。
2. 面板**左右有 ◀ ▶ 可翻页**遍历整个 tab：
   - ◀ ≈ (95, 520)，▶ ≈ (1845, 520)。
   - 翻到两端会停/回卷（实测 ▶ 到底不动）。
3. **只 OCR 标题+库存区**（省 token）：裁剪 `x 330..1700, y 195..255`，放大 2×，再跑本地 OCR：
   ```python
   from PIL import Image
   Image.open(shot).crop((330,195,1700,255)).resize((1370*2,60*2)).save("h.png")
   # 然后： python <ocr.py> h.png
   ```
   输出形如 `应急理智浓缩液10/19 03:59到期库存3`。

## 4. 理智药 item id ↔ 名称（MAA 模板 `C:\MAA\resource\template\items\`）

| 模板 | 名称 | 恢复理智 |
|---|---|---|
| `ap_supply_lt_010.png` | 应急理智小样 | +10 |
| `ap_supply_lt_60.png` | 应急理智加强剂 | +60 |
| `ap_supply_lt_80.png` / `_80_2025_1` | 应急理智强化剂 | +80 |
| `ap_supply_lt_100.png` | 应急理智顶液 | +100 |
| `ap_supply_lt_120.png` | 应急理智浓缩液 | +120 |

> 另有非 `ap_supply` 的理智恢复道具（如活动「冰皮月饼」流金影），名称需实读。

## 5. 实测（2026-10-10，消耗物品 tab，共 8 项）

| 名称 | 到期 | 库存 | 恢复理智 |
|---|---|---|---|
| 应急理智浓缩液 | 10/19 03:59 | 3 | 3×120 |
| 应急理智浓缩液 | 10/12 03:59 | 2 | 2×120 |
| 应急理智加强剂 | 10/12 03:59 | 4 | 4×60 |
| 应急理智加强剂 | 10/19 03:59 | 6 | 6×60 |
| 流金影（冰皮月饼） | 10/12 03:59 | 1 | 恢复理智（待核具体值） |
| 专业干员技巧集 | — | 1 | — |
| 数据增补仪 | 限时 | 1 | — |
| 数据增补条 | 限时 | 20 | — |

**结论：理智药合计 ≈ 5×(浓缩液) + 10×(加强剂) = 600 + 600 = 1200 理智**（+ 月饼若干）。
与「搓玉 20 天约需 1212 理智药」的缺口估算基本吻合 → 理智药是搓玉进度的关键弹性资源，**该吃就吃**。
